## 자동 실행 시간 (한국시간)

- 토요일 21:40, 일요일 09:10, 월요일 09:10에 새 결과가 있는지 확인합니다.
- 새 결과가 없으면 아무것도 바꾸지 않습니다.
- 직접 실행: 저장소의 **Actions** 탭 → **로또 데이터 업데이트 및 사이트 배포** → **Run workflow**

## 문제가 생겼을 때

- **Actions 탭에 빨간 X**: 실행 기록을 열어 어느 단계에서 멈췄는지 확인합니다. `GitHub Pages 배포` 단계라면 Settings → Pages → Source가 **GitHub Actions**인지 확인합니다.
- **새 회차가 안 들어옴**: 데이터 출처(smok95/lotto)가 아직 갱신되지 않았을 수 있습니다. 일요일·월요일에 다시 확인하고, 급하면 사이트의 결과 업데이트 탭에서 직접 입력합니다(그 브라우저에만 반영).
- **60일 넘게 커밋이 없으면** GitHub가 예약 실행을 멈춥니다. 매주 자동 커밋이 생기므로 보통은 문제없고, 멈췄다면 Actions 탭에서 **Enable workflow**를 누릅니다.
